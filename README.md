### 🚀 About me

Full-stack developer with production experience across the **React / Next.js** and **Django / PostgreSQL** stack, plus cross-platform mobile development with **Flutter**. I build responsive, SEO-optimized frontends, RESTful and real-time APIs, and own features end-to-end — from database schema to UI to deployment.

- 🏢 Built and delivered **SKATYS** (skatys.com), a production corporate platform for an SAP / digital-transformation consulting firm — Next.js (SSR/SSG) + Django REST + PostgreSQL
- 📱 Shipped **QuickDrop**, a peer-to-peer shipping marketplace app — Flutter, Firebase, real-time chat, Stripe payments
- 📺 Built **Atlas Book**, a Flutter digital-signage app for Android & Android TV (freelance, Fondation Phosboucraâ — OCP Group)
- 🌐 Freelance WordPress developer behind **Daily Salad Recipes** (custom theme, PHP, Nginx, SEO setup)
- 🎮 Built a real-time **multiplayer Pong platform** — WebSockets, 100+ concurrent players, sub-50ms latency
